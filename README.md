A make.fun entry for the bounty **The Meeting That Should Have Been an Email**: one line, at most 200 characters, that makes a meeting-that-should-have-been-an-email funny.

## The entry

> Forty-five minutes, nine people, zero decisions, and now someone has to write an email about a meeting about nothing.

## How it works

`main.py` (Python standard library only, no network, no input) writes that one line to `/output/entry.txt`. It checks the line against the gate first (1 to 200 characters, one line) and reads the file back before it exits.

Run it:

```sh
python3 main.py
```
